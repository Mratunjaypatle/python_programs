

# Database Explanation
## What Is a Database?
A **database** is an organized collection of data that can be stored, managed, searched, updated, and retrieved efficiently. Databases are used by applications, websites, businesses, and organizations to keep information structured  and accessible and safe.

For example, an online store may use a database to store:

- Customer accounts
- Product information
- Orders
- Payments
- Inventory levels
- Shipping details
## Why Databases Are Used
Databases help organizations manage large amounts of information reliably. They provide:

- **Data storage:** Keeps information in a persistent location.
- **Organization:** Structures information into meaningful categories.
- **Fast retrieval:** Allows users and applications to find data quickly.
- **Data accuracy:** Supports rules that prevent invalid or duplicate data.
- **Security:** Controls who can view, add, edit, or delete information.
- **Backup and recovery:** Helps restore data if it is lost or damaged.
- **Multi-user access:** Allows multiple users or applications to work with the same data.
## Main Components of a Database
### Tables
A table stores related information in rows and columns.

Example: A `Customers` table

| CustomerID | FirstName | LastName | Email | Order |
| ----- | ----- | ----- | ----- | ----- |
| 1 | Jane | Smith | [jane@example.com](mailto:jane@example.com)  | Apple iphone 18 pro max |
| 2 | John | Lee | [john@example.com](mailto:john@example.com)  | One Plus nord  |
### Rows
A **row**, also called a record, represents one complete item in a table.

For example, Jane Smith's information is one row in the `Customers` table.

### Columns
A **column**, also called a field or attribute, represents one type of information.

Examples of columns include:

- Customer ID
- Name
- Email address
- Phone number
- Date of birth
### Primary Key
A **primary key** is a column that uniquely identifies each row in a table.

For example, `CustomerID` can be used as a primary key because every customer should have a unique ID.

### Foreign Key
A **foreign key** creates a relationship between tables.

For example, an `Orders` table may include a `CustomerID` column that links each order to a customer in the `Customers` table.

## Types of Databases
### Relational Databases
Relational databases store data in tables and connect those tables through relationships.

Common relational database systems include:

- MySQL
- PostgreSQL
- Microsoft SQL Server
- Oracle Database
- SQLite
They commonly use **SQL** (Structured Query Language) to manage data.

### NoSQL Databases
NoSQL databases are designed for flexible, large-scale, or unstructured data. They may store data as documents, key-value pairs, graphs, or columns.

Common NoSQL databases include:

- MongoDB
- Redis
- Cassandra
- Firebase
- Neo4j
## SQL and Database Operations
SQL is a language used to interact with relational databases.

Common SQL operations include:

- `SELECT`  — retrieves data
- `INSERT`  — adds new data
- `UPDATE`  — changes existing data
- `DELETE`  — removes data
- `CREATE`  — creates database objects such as tables
- `ALTER`  — modifies existing tables
Example SQL query:

```sql
SELECT FirstName, LastName, Email
FROM Customers
WHERE CustomerID = 1;
```
This query retrieves the name and email address for the customer with ID `1`.

## Database Relationships
Tables can be related in several ways.

### One-to-One
One record in one table is connected to one record in another table.

Example:

- One employee has one employee badge.
### One-to-Many
One record in one table is connected to many records in another table.

Example:

- One customer can place many orders.
- Each order belongs to one customer.
### Many-to-Many
Many records in one table can be connected to many records in another table.

Example:

- A student can enroll in many courses.
- A course can contain many students.
A separate linking table, such as `StudentCourses`, is typically used to manage this relationship.

## Database Management System
A **Database Management System (DBMS)** is software that creates, manages, and controls databases.

A DBMS provides tools for:

- Creating tables and databases
- Running queries
- Managing user permissions
- Enforcing data rules
- Performing backups
- Restoring data
- Monitoring performance
## Database Security
Database security protects information from unauthorized access, modification, or loss.

Common security measures include:

- User authentication
- Role-based permissions
- Password policies
- Encryption
- Data backups
- Audit logs
- Firewall protection
- Regular software updates
For example, a customer service employee may be able to view customer records but not delete them.

## Summary
A database is a system for storing and managing structured information. It organizes data into formats that can be searched, updated, secured, and shared efficiently. Databases are essential for modern applications because they support reliable data storage, business operations, reporting, and decision-making.

# SQL Explanation
## What Is SQL?
**SQL** stands for **Structured Query Language**. It is the standard language used to work with relational databases.

SQL lets you:

- Create databases and tables
- Store data
- Retrieve data
- Update existing records
- Delete records
- Control user access and permissions
Common relational database systems that use SQL include:

- MySQL
- PostgreSQL
- Microsoft SQL Server
- Oracle Database
- SQLite
## Core Database Concepts
### Database
A database is an organized collection of data.

Example: A company may have a database containing employees, customers, orders, and products.

### Table
A table stores data in rows and columns.

Example `Employees` table:

| EmployeeID | FirstName | LastName | Department |
| ----- | ----- | ----- | ----- |
| 1 | Alice | Smith | Sales |
| 2 | Bob | Jones | Engineering |
- **Rows** represent individual records.
- **Columns** represent attributes of each record.
### Primary Key
A primary key is a column, or combination of columns, that uniquely identifies each row.

```sql
EmployeeID INT PRIMARY KEY
```
In the `Employees` table, `EmployeeID` can identify every employee uniquely.

## Common SQL Commands
SQL statements are commonly grouped into several categories.

### Querying Data: `SELECT` 
Use `SELECT` to retrieve data from a table.

```sql
SELECT FirstName, LastName
FROM Employees;
```
This returns the first and last names of all employees.

To retrieve every column:

```sql
SELECT *
FROM Employees;
```
### Filtering Data: `WHERE` 
Use `WHERE` to return only rows that match a condition.

```sql
SELECT *
FROM Employees
WHERE Department = 'Sales';
```
```sql
SELECT *
FROM Employees
WHERE EmployeeID > 10;
```
### Sorting Data: `ORDER BY` 
Use `ORDER BY` to sort results.

```sql
SELECT *
FROM Employees
ORDER BY LastName ASC;
```
- `ASC`  sorts ascending, which is the default.
- `DESC`  sorts descending.
```sql
SELECT *
FROM Employees
ORDER BY EmployeeID DESC;
```
### Limiting Results
Many databases support `LIMIT`:

```sql
SELECT *
FROM Employees
LIMIT 5;
```
Microsoft SQL Server commonly uses:

```sql
SELECT TOP 5 *
FROM Employees;
```
### Adding Data: `INSERT` 
Use `INSERT` to add a new row.

```sql
INSERT INTO Employees (EmployeeID, FirstName, LastName, Department)
VALUES (3, 'Carol', 'Brown', 'Marketing');
```
### Updating Data: `UPDATE` 
Use `UPDATE` to modify existing rows.

```sql
UPDATE Employees
SET Department = 'Operations'
WHERE EmployeeID = 3;
```
>  Always use a `WHERE` clause when updating specific records. Without it, every row may be updated. 

### Deleting Data: `DELETE` 
Use `DELETE` to remove rows.

```sql
DELETE FROM Employees
WHERE EmployeeID = 3;
```
>  Always verify the `WHERE` condition before running a `DELETE` statement. 

## Creating Tables
Use `CREATE TABLE` to define a new table.

```sql
CREATE TABLE Employees (
    EmployeeID INT PRIMARY KEY,
    FirstName VARCHAR(50) NOT NULL,
    LastName VARCHAR(50) NOT NULL,
    Department VARCHAR(100),
    HireDate DATE
);
```
Common data types include:

| Data Type | Purpose |
| ----- | ----- |
| `INT`  | Whole numbers |
| `DECIMAL(10,2)`  | Exact decimal numbers, such as currency |
| `VARCHAR(255)`  | Variable-length text |
| `DATE`  | Calendar date |
| `BOOLEAN`  | True or false value |
## Aggregating Data
Aggregate functions calculate values across multiple rows.

```sql
SELECT COUNT(*) AS TotalEmployees
FROM Employees;
```
Common aggregate functions:

| Function | Description |
| ----- | ----- |
| `COUNT()`  | Counts rows or non-null values |
| `SUM()`  | Adds numeric values |
| `AVG()`  | Calculates an average |
| `MIN()`  | Finds the smallest value |
| `MAX()`  | Finds the largest value |
Example:

```sql
SELECT Department, COUNT(*) AS EmployeeCount
FROM Employees
GROUP BY Department;
```
This returns the number of employees in each department.

To filter grouped results, use `HAVING`:

```sql
SELECT Department, COUNT(*) AS EmployeeCount
FROM Employees
GROUP BY Department
HAVING COUNT(*) > 5;
```
## Joining Tables
A **join** combines related data from multiple tables.

Example tables:

- `Employees` 
- `Departments` 
```sql
SELECT
    Employees.FirstName,
    Employees.LastName,
    Departments.DepartmentName
FROM Employees
INNER JOIN Departments
    ON Employees.DepartmentID = Departments.DepartmentID;
```
### Common Join Types
| Join Type | Result |
| ----- | ----- |
| `INNER JOIN`  | Returns rows with matches in both tables |
| `LEFT JOIN`  | Returns all rows from the left table and matching rows from the right |
| `RIGHT JOIN`  | Returns all rows from the right table and matching rows from the left |
| `FULL OUTER JOIN`  | Returns all rows from both tables where supported |
## Example Query
Retrieve orders over $100, sorted from highest to lowest:

```sql
SELECT OrderID, CustomerID, TotalAmount
FROM Orders
WHERE TotalAmount > 100
ORDER BY TotalAmount DESC;
```
## SQL Best Practices
- Use `WHERE`  carefully with `UPDATE`  and `DELETE` .
- Prefer specific column names over `SELECT *`  in production queries.
- Use parameterized queries to prevent SQL injection.
- Name tables and columns consistently.
- Use indexes for columns frequently used in filters, joins, and sorting.
- Test destructive statements with `SELECT`  first.
- Use transactions for related operations that must succeed or fail together.
```sql
BEGIN;

UPDATE Accounts
SET Balance = Balance - 100
WHERE AccountID = 1;

UPDATE Accounts
SET Balance = Balance + 100
WHERE AccountID = 2;

COMMIT;
```
If an error occurs before completion, use:

```sql
ROLLBACK;
```
